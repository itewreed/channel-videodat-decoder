# channel-videodat-decoder
A decoder for channel videodat, that was aired in the VBI of Pro7 from 1990 to 1994. It decodes from vbi captures from bt8x8 cards and tbc files from vhs-decode.

Decoder für Pro7-VideoDat (1990 - 1994) aus Roh-VBI-Aufnahmen
(bttv /dev/vbi0, PAL, 2048 Samples/Zeile, 32 Zeilen/Bild) oder aus
TBC-Dateien von vhs-decode/ld-decode (16 Bit, 4*fsc = 17,73 MHz,
1135 Samples x 313 Zeilen je Halbbild, inkl. Sync).
